# CHANGELOG - SAN AURELIO

## [v0.1.0-alpha] - 2026-09-30
### Initial Production Build & Architecture Implementation
- Implemented full 26-zone canonical world map architecture with interactive map viewer, POI filtering, and GPS ribbon routing.
- Delivered procedural 3D hero character controller for Kai Mercer (Mira Kade) with 3rd-person camera, multi-speed locomotion, jumping, vaulting, and weapon socket integration.
- Built 10 comprehensive vehicle systems (Sports Coupe, Sedan, Utility Pickup, Panel Van, Compact, Motorbike, Speedboat, Helicopter with flight physics, and Light Tank with rotating turret).
- Developed 6-class combat subsystem (Pistol, SMG, Shotgun, Assault Rifle, Marksman Rifle, Heavy Launcher) with hitscan raycasts, weapon recoil, muzzle flash, and hit feedback.
- Implemented 0-5 Star Wanted level law enforcement escalation with AMPS police cruisers, pursuit AI, search cones, and evasion cooldown.
- Built data-driven mission engine featuring multi-stage story heists, street sprints, and courier deliveries.
- Integrated Web Audio API procedural synthesizer for vehicle RPM sound beds, gunshots, tire squeals, sirens, and ambient city audio.
- Developed versioned save/load system supporting IndexedDB and LocalStorage fallback.
- Added comprehensive in-game HUD, minimap, smartphone menu, weapon radial wheel, and debug profiler.
